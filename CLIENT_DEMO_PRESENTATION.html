المتطلبات

  • Docker Desktop يعمل على Windows.
  • مجلد المشروع كامل، وPowerShell مفتوح عليه.
  • قاعدة بيانات محلية تجريبية؛ لا تستخدم بيانات الإنتاج.
  • وقت أول تشغيل، اترك Docker يبني الحاويات ويجهز قاعدة البيانات.

ملف الإعداد المحلي

إذا لم يوجد .env، أنشئه من القالب. لو موجود بالفعل، لا تستبدله.

Set-Location D:\work\JusoorProject
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env

ولّد مفتاحين محليين مختلفين بطول 64 و32 بايت:

$rng = [Security.Cryptography.RandomNumberGenerator]::Create()
$bytes = New-Object byte[] 64
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes)
$bytes = New-Object byte[] 32
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes)
$rng.Dispose()

استخدم المخرجين في JWT_SIGNING_KEY وFIELD_ENCRYPTION_LOCAL_KEY، وضع كلمة مرور محلية لـ POSTGRES_PASSWORD وحساب عرض تجريبي. لا تشارك `.env` أو تظهره للعميل.

لو هنجرّب رفع فيديو: أعدّ مسبقًا Supabase Storage تجريبيًا واضبط عنوان المشروع واسم الـ bucket ومفتاح الخدمة على الخادم فقط، مع إعداد القراءة العامة وCORS لعنوان http://localhost:3000. لا تضع مفتاح الخدمة في الواجهة أو العرض.
ملاحظة للمقدّم
المفاتيح مطلوبة لتشغيل API محليًا. لم نضمّن أي مفاتيح في هذا العرض. إعداد Supabase ليس مطلوبًا لكتابة خبر نصي، لكنه مطلوب لرفع وتشغيل الصور والفيديوهات الفعلية. حضّر حسابين محليين منفصلين: ابدأ بـ DEV_SEED_EMAIL وDEV_SEED_PASSWORD وDEV_SEED_ROLE=Reporter، شغّل الـ API مرة؛ ثم غيّر البريد وكلمة المرور إلى حساب ثانٍ واجعل الدور ManagingEditor، وشغّل docker compose up -d --force-recreate api. المراسل يكتب ويرسل، ومدير التحرير يراجع وينشر.

أمر واحد يبدأ الخدمات

من جذر المشروع، وبعد حفظ إعدادات `.env` وبدء Docker Desktop:

PowerShell — من مجلد المشروع

Set-Location D:\work\JusoorProject
docker compose up --build -d
docker compose ps

لو احتجنا نعرف سبب مشكلة تشغيل

docker compose logs --tail 80 api web

إيه اللي بيحصل؟

  • تشغيل PostgreSQL وRedis وواجهة API وموقع Next.js.
  • في وضع Development، الـ API يطبّق ترحيلات قاعدة البيانات ويجهز أدوار غرفة الأخبار تلقائيًا.
  • بعد أول تجهيز، الصفحات متاحة محليًا على الكمبيوتر.
الموقع: localhost:3000الـ API: localhost:5000Swagger: localhost:5000/swagger
لإيقاف العرض استخدم docker compose down. لا تستخدم docker compose down -v إلا إذا كنت تقصد حذف قاعدة بيانات التجربة وكل محتواها.
ملاحظة للمقدّم
قاعدة البيانات المحليّة منشأة داخل Docker على منفذ 5433 من جهة Windows لتجنب تعارض PostgreSQL محلي. انتظر حتى تظهر الخدمات عاملة في docker compose ps، وافتح Swagger إذا أردت إظهار أن الواجهة تتصل بخلفية API حقيقية. لا تعرض شاشة .env أو قيم الدخول.

الفيديو المختار يصل لصفحة الفيديوهات

رفع الفيديو وإدراجه في الخبر لا يعني نشره في المركز تلقائيًا؛ المحرر يختار أي فيديو يمثّل الخبر.

خطوات الوصول إلى المركز

  1. ارفع فيديو جاهزًا من مكتبة الوسائط وأدرجه داخل المتن.
  2. اختر الفيديو المراد تمييزه في «قسم الفيديوهات».
  3. احفظ وأكمل المراجعة ثم انشر الخبر.
  4. افتح /videos: يظهر الفيديو المنشور مع تاريخ واعتماد ورابط للخبر.

ما سيشاهده العميل
